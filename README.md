# aptly-gui

GUI aplikace pro správu Debian repozitářů pomocí nástroje [aptly](https://www.aptly.info/).

## Stav projektu

Projekt je v přípravné fázi. Zatím nebyla zvolena technologie ani architektura —
čeká se na návrh a rozhodnutí ve spolupráci s uživatelem (např. desktopová vs.
webová aplikace, konkrétní framework, způsob komunikace s aptly).

## Cíl

Poskytnout grafické rozhraní nad funkcemi aptly, typicky zahrnujícími:

- správu repozitářů (vytváření, editace, mazání)
- správu balíčků (import, přesun, odstranění)
- publikování snapshotů/repozitářů
- práci s mirrory
